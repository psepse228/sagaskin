# SAGA

Korean skincare e-commerce site — rebrand + rebuild of the previous
Sagaskin static site, on Next.js. See [CLAUDE.md](./CLAUDE.md) for stack,
folder layout, and design system notes; see
[docs/client-brief/](./docs/client-brief/) for wireframes and brand
reference from the client.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
